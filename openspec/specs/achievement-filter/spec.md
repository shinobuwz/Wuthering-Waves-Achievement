# 成就过滤规范

## 需求

### 需求:隐藏已完成成就
成就管理界面必须提供"隐藏已完成"复选框过滤选项。勾选后，列表中禁止显示 `获取状态` 为 `已完成` 的成就条目。该过滤必须与搜索文本、版本、分类、隐藏类型、获取类型等过滤条件叠加生效（AND 逻辑）。

#### 场景:勾选隐藏已完成
- **当** 用户勾选"隐藏已完成"复选框
- **那么** 列表中所有 `获取状态 == "已完成"` 的成就条目立即消失，其余条目保持不变

#### 场景:取消隐藏已完成
- **当** 用户取消勾选"隐藏已完成"复选框
- **那么** 之前被隐藏的已完成成就条目重新显示在列表中

#### 场景:与分类过滤叠加
- **当** 用户已选中某个二级分类且勾选了"隐藏已完成"
- **那么** 列表只显示该二级分类下且状态不为"已完成"的成就

#### 场景:切换分类后保持勾选
- **当** 用户在勾选"隐藏已完成"后切换一级或二级分类
- **那么** 复选框仍保持勾选状态，新分类下同样隐藏已完成成就

#### 场景:与搜索叠加
- **当** 用户已输入搜索关键词且勾选了"隐藏已完成"
- **那么** 列表只显示名称/描述匹配关键词且状态不为"已完成"的成就
